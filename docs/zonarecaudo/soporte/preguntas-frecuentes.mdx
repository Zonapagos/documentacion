--- 
title: Preguntas frecuentes 
--- 

Las dudas más comunes al integrar con Zonapagos.

<AccordionGroup>

<Accordion title="¿Puedo eliminar una factura?"> 
No. Solo es posible archivarla. 
</Accordion>
 
<Accordion title="¿Qué ocurre si vuelvo a importar una factura?">
Se actualizará si está habilitada la opción **Sobrescribir duplicados**. 
</Accordion> 
 
<Accordion title="¿Cómo funciona descartar registros anteriores?">
Archiva automáticamente el cargue previo. 
</Accordion> 
 
<Accordion title="¿Puedo tener varias fechas de vencimiento?">
Sí. Debe definirse durante la configuración inicial. 
</Accordion>
 
<Accordion title="¿El usuario puede cambiar información?">
Sí, dependiendo de la parametrización del comercio. 
</Accordion>

<Accordion title="¿Una vez realizado el cargue, se puede modificar algún registro?"> 
Sí. Las facturas cargadas o creadas manualmente pueden actualizarse desde el módulo administrativo. Sin embargo, por políticas de auditoría, 
las facturas no pueden eliminarse; únicamente pueden cambiarse al estado Archivado.  
</Accordion>

<Accordion title="¿La modalidad Zonarecaudo Portal permite configurar varias listas desplegables?"> 
Sí. El portal permite incorporar campos configurables de acuerdo con las necesidades del comercio. La definición de listas desplegables y demás campos 
debe establecerse durante la etapa de configuración e implementación del proyecto.   
</Accordion>

<Accordion title="¿Con qué frecuencia se pueden realizar los cargues de información?"> 
La frecuencia de cargue es definida por el comercio durante la configuración inicial del proyecto. Los cargues pueden realizarse de forma diaria, semanal o mensual, 
según la operación y necesidades del recaudo.   
</Accordion>

<Accordion title="¿Se pueden configurar algunos campos como obligatorios y otros como opcionales?"> 
Sí. Durante la implementación se definen los campos requeridos para el recaudo. Adicionalmente, el comercio puede configurar funcionalidades opcionales para el 
usuario pagador, como la modificación de correo electrónico, número celular, valor de pago o la realización de abonos parciales. 
</Accordion>

<Accordion title="¿La base de datos se puede integrar con el CRM interno de la empresa?"> 
La información de recaudo se administra mediante archivos de cargue definidos durante la implementación. Si se requiere integración con sistemas internos como CRM 
o ERP, es necesario realizar una validación técnica para determinar la viabilidad y el mecanismo de integración más adecuado.  
</Accordion>

<Accordion title="¿Cuántas fechas de vencimiento máximas se pueden utilizar en los registros?"> 
El número de fechas de vencimiento que manejará cada factura debe definirse durante la configuración inicial del proyecto. Zonarecaudo Portal admite múltiples 
fechas de vencimiento por registro, de acuerdo con la parametrización establecida para el comercio. 
<Note> Si en la implementación existe un límite específico (por ejemplo, 3, 5 o 10 fechas de vencimiento), sería recomendable incluirlo explícitamente en esta respuesta. 
Actualmente la documentación solo indica que la cantidad se define durante la configuración inicial. </Note>
</Accordion>

</AccordionGroup>
