# Introducción 
 
El modelo de recaudo por base de datos está diseñado para comercios que ya conocen previamente las obligaciones que deben recaudar y administran periódicamente las facturas que estarán 
disponibles para pago. 
 
Un ejemplo común es una empresa de arrendamientos que conoce cada mes cuáles son los clientes que deben realizar pagos. 
 
En este esquema, el comercio administra previamente las facturas y Zonapagos publica la información para consulta y pago. 
 
--- 
 
## Consideraciones antes de crear el proyecto 
 
Antes de iniciar la implementación del portal, el comercio debe definir las siguientes configuraciones. 
 
<CardGroup cols={2}> 
 
<Card title="Cantidad de registros"> 
 
Definir el volumen inicial de facturas que serán cargadas. 
 
Este límite podrá ampliarse posteriormente. 
 
</Card> 
 
<Card title="Frecuencia de cargue"> 
 
Determinar si las facturas serán cargadas: 
 
- Diario 
- Semanal 
- Mensual 
 
</Card> 
 
<Card title="Fechas de vencimiento"> 
 
Definir cuántos vencimientos manejará cada factura. 
 
</Card> 
 
<Card title="Edición por usuario"> 
 
Definir qué campos podrá modificar el usuario pagador. 
 
</Card> 
 
</CardGroup> 
 
--- 
 
## Configuraciones opcionales para el usuario pagador 
 
El comercio podrá definir si el usuario podrá: 
 
- Modificar correo electrónico 
- Modificar número celular 
- Ingresar valor de pago 
- Realizar abonos parciales
