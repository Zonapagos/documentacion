# Portal de recaudo

El portal de recaudo permite centralizar el proceso de consulta y recepción de pagos.

Las empresas pueden definir:

- Campos visibles
- Criterios de búsqueda
- Reglas de recaudo
- Comportamiento del pago
- Flujo administrativo
