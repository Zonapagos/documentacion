# Introducción

Zonarecaudo es una solución diseñada para facilitar la consulta, administración y recaudo de pagos asociados a facturas o servicios prestados.

Permite que las empresas integren sus procesos de recaudo utilizando un portal administrado por Zonapagos o mediante integración con servicios REST para operación en tiempo real.
