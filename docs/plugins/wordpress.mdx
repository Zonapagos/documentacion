Wordpress es un sistema de gestión de contenidos (CMS) que permite crear sitios web dinámicos y personalizables. Woocommerce es un plugin que se instala dentro de wordpress y 
convierte el sitio en una tienda virtual. Proporciona todas las funcionalidades necesarias para vender productos o servicios en línea: catálogo, carrito de compras, pasarela 
de pagos, gestión de pedidos, entre otros.

## Requisitos.
Es importante que tu entorno de desarrollo y producción cumpla con las siguientes condiciones antes de integrar el plugin.
| Requisito | Descripción |
|-----------|-------------|
| **WordPress** | Versión **5.8** o superior (recomendado: **6.7.2+**). |
| **WooCommerce** | Versión **4.0** o superior. |
| **Permisos de administración** | Debes tener permisos de administrador en WordPress para instalar nuevos plugins. |
| **PHP** | Versión **7.4** o superior. |
| **Certificado SSL** | Sitio web con **HTTPS** activo. |
| **Haber completado el proceso de vinculación** | Debes tener una cuenta activa para contar con todas las llaves necesarias para la integración. |

## Medios de pago
El plugin puede habilitar los medios de pago que tu elijas.

**PSE**
Transferencias bancarias

**Tarjetas de crédito/Débito**

**Billeteras Digitales**
Nequi y Daviplata

**Efectivo**
Corresponsales Bancarios o Caja


## ¿Qué permite el plugin?
Con esta integración podrás transformar la experiencia de compra en tu tienda en línea, facilitando el pago para tus clientes y optimizando la gestión de tus transacciones. 
El plugin te permite:

### <Icon icon="dollar-sign" /> Aceptar pagos en línea
directamente desde tu tienda Woocommerce.

### <Icon icon="credit-card" /> Ofrecer múltiples medios de pago en un solo flujo
tarjetas débito/crédito, PSE, Nequi, Daviplata, Botón Bancolombia, corresponsales bancarios y más. 

### <Icon icon="chart-line" /> Gestionar transacciones
y estados de pago desde el administrador de Wordpress y el modulo administrativo zonapagos.

### <Icon icon="lock" /> Cumplir con los estándares de seguridad PCI DSS
garantizando transacciones protegidas sin exponer los datos sensibles del cliente.

## Flujo de pago con el plugin
Permite integrar el flujo de pagos de forma directa en el proceso de compra de tu tienda en línea, ofreciendo una experiencia segura y fluida para el usuario final.

### <Icon icon="shopping-bag" /> El usuario pagador selecciona los productos o servicios
 en la tienda en línea y los agrega al carrito de compras.

### <Icon icon="credit-card" /> El usuario es redirigido
a la pasarela de pagos de zonapagos, selecciona el medio de pago e ingresa sus datos.

### <Icon icon="phone" /> Zonapagos procesa la transacción
el usuario es redirigido de nuevo a la tienda con la confirmación del pago.

### <Icon icon="circle-info" /> El estado del pedido se actualiza
automáticamente en woocommerce según el resultado (aprobado, rechazado o pendiente)  y en el modulo administrativo Zonapagos.
