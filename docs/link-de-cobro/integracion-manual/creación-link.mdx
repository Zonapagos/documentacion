---
title: "Link de pago manual"
---

La modalidad manual permite generar links de pago directamente desde el portal administrativo de Zonapagos.

### Ideal para: 
- Comercios pequeños
- Cobros ocasionales
- Atención vía WhatsApp
- Facturación manual


## Flujo operativo

Operador → Portal Zonapagos → Generar Link → Compartir → Cliente paga

### Proceso
<Steps>
Ingresar al portal administrativo.
</Step>
<Step> 
Seleccionar “Crear Link de Pago”. 
</Step>
<Step> 
Registrar:
- Factura
- Cliente
- Valor
- Concepto
</Steps>
<Step>
Generar el link. 
</Step>
<Step> 
Compartir mediante:
- Email
- WhatsApp
- SMS
</Step>


## Casos de uso

| Caso               | Descripción             |
| ------------------ | ----------------------- |
| Cobro por WhatsApp | Envío rápido de links   |
| Ventas manuales    | Operación sin ecommerce |
| Facturación rápida | Cobros individuales     |


## Ventajas

- No requiere desarrollo
- Implementación inmediata
- Gestión centralizada
- Compatible con múltiples medios de pago

## Limitaciones

- No automatizable
- Dependencia operativa manual
- Mayor riesgo de errores humanos
