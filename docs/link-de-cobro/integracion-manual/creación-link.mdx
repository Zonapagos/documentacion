---
title: "Introducción"
---

La modalidad manual permite generar links de pago directamente desde el portal administrativo de Zonapagos.

### Ideal para: 
- Comercios pequeños
- Cobros ocasionales
- Atención vía WhatsApp
- Facturación manual


## Flujo operativo

```text
Operador → Portal Zonapagos → Generar Link → Compartir → Cliente paga
```

### Proceso

<Steps>
  <Step title="1. Ingresar al portal administrativo">
    Accede al portal administrativo con tus credenciales.
  </Step>

  <Step title='2. Seleccionar "Crear Link de Pago"'>
    Dirígete a la sección de pagos y selecciona la opción 
    <code>Crear Link de Pago</code>.
  </Step>

  <Step title="3. Registrar información del pago">
    Completa los siguientes campos requeridos:

    - Factura
    - Cliente
    - Valor
    - Concepto
  </Step>

  <Step title="4. Generar el link">
    Haz clic en el botón <code>Generar</code> para crear el link de pago.
  </Step>

  <Step title="5. Compartir el link">
    Comparte el link generado con el cliente a través de:

    - Email
    - WhatsApp
    - SMS
  </Step>
</Steps>

## Casos de uso

| Caso               | Descripción             |
| ------------------ | ----------------------- |
| Cobro por WhatsApp | Envío rápido de links   |
| Ventas manuales    | Operación sin ecommerce |
| Facturación rápida | Cobros individuales     |


## Ventajas

- No requiere desarrollo
- Implementación inmediata
- Gestión centralizada
- Compatible con múltiples medios de pago

## Limitaciones

- No automatizable
- Dependencia operativa manual
- Mayor riesgo de errores humanos
