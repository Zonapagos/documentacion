---
title: "Crear Link de Pago"
---

## Ruta

Dentro de la taquilla:

```text
Pedidos y Pagos → Crear Link de Pago
```

---

## Formulario

Completar:

| Campo | Descripción |
|---|---|
| Id Pago | Identificador transacción |
| Identificación | Documento cliente |
| Nombre completo | Nombre cliente |
| Total con IVA | Valor total |
| Valor IVA | IVA |
| Concepto | Descripción pago |
| Disponibilidad link | Fecha expiración |

---

## Crear Link

Dar clic en:

```text
Crear y compartir
```
