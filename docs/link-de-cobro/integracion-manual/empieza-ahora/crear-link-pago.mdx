### Correo

1.  Si se selecciona “Compartir por Correo”, aparece el campo para digitar el o los correos a los cuales se va a enviar el 
link de pago. 
<div style={{ textAlign: "center", margin: "24px 0" }}>
<img 
    src="/docs/imagenes/compartir-correo.jpg"
    style={{

de pago”, aparece un mensaje indicando “El link de pago fue enviado exitosamente a:”

link de pago:
