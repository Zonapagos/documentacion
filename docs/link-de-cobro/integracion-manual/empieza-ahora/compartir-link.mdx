---
title: "Compartir Link"
---

## Métodos Disponibles

- WhatsApp
- Correo

---

# Compartir Correo

## Flujo

1. Seleccionar Compartir por Correo.
2. Ingresar correos destino.
3. Dar clic en:

```text
Enviar link de pago
```

---

## Resultado

El usuario recibe un correo con:

- Información pago
- Botón “Pagar con Zonapagos”
- URL transaccional

---

# Compartir WhatsApp

## Flujo

1. Seleccionar Compartir WhatsApp.
2. Ingresar número celular.
3. Dar clic en:

```text
Compartir link de pago
```

---

## Resultado

Se abre WhatsApp Web automáticamente con el mensaje cargado.
