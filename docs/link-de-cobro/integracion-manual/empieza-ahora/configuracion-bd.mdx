Para completar la configuración del comercio como link de pago se debe realizar una parametrización por base de datos, para ello 
se le debe asignar un caso de zonayuda al equipo de Operaciones con la siguiente configuración: 

---

## Configuraciones Requeridas

Configurar por base de datos los mismos pasos de link de pagos (poner los pasos). Existe un txt con esos pasos en la parte 
que dice “*id comercio* debe ir el id único de la taquilla.

### Base Transacciones

Crear el consecutivo para el 
comercio que va a ser link de pagos NC 

- pag_pago_consecutivos
- pag_consecutivos_pago

---

### Base Facturas

En la bd de facturas debe de tener el registro en la tabla:

```text
tiv_pagos_parametros
```

---

### Base Coordinadora

En la bd coordinadora en la tabla:

```text
idio_correo_x_comercio
```
Realizar insert al comercio.
