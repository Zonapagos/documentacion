---
Title. "Preguntas frecuentes"
---

Las dudas más comunes al integrar con Zonapagos.

<AccordionGroup>
  <Accordion title="¿Qué es un Link de Cobro?">
    El Link de Cobro es una funcionalidad que permite generar un enlace de pago para compartir con tus clientes por diferentes canales, como WhatsApp, correo electrónico, SMS o redes sociales. El cliente podrá acceder al enlace y realizar el pago de forma rápida y segura sin necesidad de que el comercio cuente con un sitio web.
  </Accordion>

  <Accordion title="¿Necesito tener un sitio web para utilizar el Link de Cobro?">
    No. El Link de Cobro está diseñado para que puedas recibir pagos sin necesidad de contar con una página web o tienda en línea. Solo debes generar el enlace y compartirlo con tu cliente.
  </Accordion>

  <Accordion title="¿Cómo creo un Link de Cobro?">
    Ingresa al módulo administrativo con tus credenciales, dirígete al menú <strong>Pedidos y pagos</strong>, selecciona <strong>Crear Link de Pago</strong>, diligencia la información solicitada y, una vez creado, podrás copiar o compartir el enlace con tus clientes.
  </Accordion>

  <Accordion title="¿Por qué canales puedo compartir el Link de Cobro?">
    Puedes compartir el enlace mediante WhatsApp, correo electrónico, SMS, redes sociales o cualquier otro canal de comunicación que utilices con tus clientes.
  </Accordion>

  <Accordion title="¿Puedo definir el valor que pagará mi cliente?">
    Sí. Al crear el Link de Cobro puedes configurar el valor que deseas cobrar, de acuerdo con la operación que necesites realizar.
  </Accordion>

  <Accordion title="¿Es posible configurar la vigencia del Link de Cobro?">
    Sí. Puedes definir la vigencia del enlace al momento de su creación para controlar el período durante el cual estará disponible para recibir pagos.
  </Accordion>

  <Accordion title="¿Qué medios de pago puede utilizar el cliente?">
    Los medios de pago disponibles dependerán de la configuración realizada para el comercio y de los servicios habilitados en la plataforma, permitiendo que el cliente seleccione una de las opciones disponibles durante el proceso de pago.
  </Accordion>

  <Accordion title="¿El Link de Cobro es seguro?">
    Sí. Todas las transacciones realizadas mediante el Link de Cobro se procesan a través de la plataforma Zonapagos, la cual implementa mecanismos de seguridad para proteger la información y garantizar la integridad de las transacciones.
  </Accordion>

  <Accordion title="¿Qué sucede cuando mi cliente realiza el pago?">
    Una vez el pago es aprobado, la transacción queda registrada en la plataforma y podrá ser consultada desde el módulo administrativo para realizar el respectivo seguimiento y conciliación.
  </Accordion>

  <Accordion title="¿Puedo generar varios Links de Cobro al mismo tiempo?">
    Sí. Puedes crear tantos Links de Cobro como requiera tu operación, facilitando la gestión de múltiples clientes o diferentes solicitudes de pago.
  </Accordion>

  <Accordion title="¿Dónde puedo consultar los Links de Cobro creados?">
    Los enlaces generados pueden administrarse desde el módulo administrativo, donde podrás consultar su información y realizar seguimiento a las transacciones asociadas.
  </Accordion>

  <Accordion title="¿Qué beneficios ofrece el Link de Cobro?">
    El Link de Cobro ofrece múltiples ventajas para la gestión de pagos:
    <ul>
      <li>No requiere tener una página web.</li>
      <li>Se puede compartir fácilmente por diferentes canales.</li>
      <li>Permite configurar el valor y la vigencia del cobro.</li>
      <li>Facilita la creación de cobros sin conocimientos técnicos.</li>
      <li>Genera reportes para el seguimiento de las transacciones.</li>
    </ul>
  </Accordion>
</AccordionGroup>
