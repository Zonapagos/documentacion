---
title: Introducción
---

Un link de cobro es una URL que contiene toda la información de la transacción que se desea realizar. La integración de **Link de Cobro Zonapagos** permite generar enlaces de pago para que los clientes realicen transacciones electrónicas utilizando:

- PSE
- Tarjetas de crédito
- Otros medios habilitados por Zonapagos

--- 

# Arquitectura general

```text
Cliente → Comercio → Zonapagos → Entidad Financiera
```
## Flujo General
1. El comercio genera un link de pago.
2. El cliente accede al enlace.
3. Zonapagos procesa la transacción.
4. Zonapagos notifica el resultado del pago al comercio.
