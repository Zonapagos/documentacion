---
title: Empezar
---

<Steps>
  <Step title="Elige el tipo de integración">
    Puedes usar integración manual o API REST dependiendo de tu necesidad.
  </Step>

  <Step title="Configura tu comercio">
    Realiza la configuración de la taquilla o credenciales API.
  </Step>

  <Step title="Crea el link de pago">
    Genera el link manualmente o vía API.
  </Step>

  <Step title="Comparte el link">
    Puedes enviarlo por correo, WhatsApp o integrarlo en tu sistema.
  </Step>
</Steps>

<Warning>
La configuración inicial debe realizarse correctamente antes de crear links de pago.
</Warning>
