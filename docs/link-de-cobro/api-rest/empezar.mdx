# Descripción

La modalidad API permite generar links de pago dinámicamente desde:

- ERP
- CRM
- Ecommerce
- Backend personalizado
- Apps móviles

<Check> La API recibe la información de la factura y retorna una URL única de pago. </Check>

# Endpoint

URL del servicio utilizada para enviar solicitudes y recibir respuestas del sistema.

```
POST /ApiPagosN3/api/LinkCreacion
```

## Headers 

`Content-Type: application/json`
