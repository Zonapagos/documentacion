## Parametros principales

Los parametros y valores deben ser enviados en formato JSON

| Parámetro          | Tipo    | Obligatorio | Descripción                         |
| ------------------ | ------- | ----------- | ----------------------------------- |
| `IdComercio`       | Integer | Sí          | Identificador del comercio          |
| `TipoAccion`       | Integer | Sí          | `0` Crear / `1` Editar              |
| `EstadoLink`       | Integer | Sí          | `1` Activo / `5` Inactivo           |
| `str_usuario`      | String  | Sí          | Usuario API entregado por Zonapagos |
| `str_clave`        | String  | Sí          | Clave API                           |
| `IdFactura`        | String  | Sí          | Número único de factura             |
| `TotalconIva`      | Double  | Sí          | Valor total de la transacción       |
| `Concepto`         | String  | Sí          | Descripción del pago                |
| `FechaVencimiento` | String  | No          | Fecha máxima de pago                |
| `EnviarLinkPago`   | Integer | No          | `1` Sí / `0` No                     |
