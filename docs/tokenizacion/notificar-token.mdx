---
title: "Notificar Token"
---

El método registra los tokens generados para cada cliente.

## Endpoint sugerido

```text
https://dominio_comercio/ApiToken/api/Notificar
```

## Características

- Método: `POST`
- Formato: `JSON`

---

## Request

| Parámetro | Tipo | Descripción |
|---|---|---|
| int_id_comercio | Numérico | Identificador del comercio |
| str_usuario | String | Usuario validador |
| str_clave | String | Clave de validación |
| str_id_cliente | String | Documento del cliente |
| str_token | String | Token generado |

### Ejemplo Request

```json
{
  "int_id_comercio": 678,
  "str_usuario": "usuario",
  "str_clave": "Agosto17",
  "str_id_cliente": "1035437342",
  "str_token": "1842154537000000001169"
}
```

---

## Response

| Código | Descripción |
|---|---|
| 0 | Token recibido exitosamente |
| 1 | No se pudo recibir |
| 2 | Error autenticación |
| 99 | Error técnico |

### Ejemplo Response

```json
{
  "int_cod_estado": 0,
  "str_mensaje": "Se recibió exitosamente el token"
}
```
