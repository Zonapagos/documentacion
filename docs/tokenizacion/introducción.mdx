La integración de **Tokenización NC** de Zonapagos permite a los comercios realizar pagos utilizando tarjetas tokenizadas de forma segura, facilitando procesos 
de cobro recurrente y almacenamiento seguro de medios de pago.

Esta documentación describe el proceso completo de integración de los servicios API relacionados con:

- Inicio de pago
- Generación y notificación de tokens
- Pagos recurrentes
- Verificación del estado de transacciones

## Características de la integración

- Comunicación mediante servicios REST
- Mensajería en formato JSON
- Integración segura mediante credenciales de comercio
- Soporte para tokenización y recurrencia
- Consulta del estado de pagos y transacciones

## Flujo General

1. El comercio inicia el pago.
2. Zonapagos genera la URL de pago.
3. El cliente realiza la transacción.
4. Zonapagos retorna el resultado.
5. El comercio puede consultar el estado del pago.
