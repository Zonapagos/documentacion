---
title: "Tokenización"
---

La integración Inicio de Pago Tokenización permite iniciar transacciones electrónicas mediante consumo API REST.

La solución soporta:

- Tokenización NC
- Recurrencia
- Verificación de pagos
- Consulta de estados transaccionales

## Flujo General

1. El comercio inicia el pago.
2. Zonapagos genera la URL de pago.
3. El cliente realiza la transacción.
4. Zonapagos retorna el resultado.
5. El comercio puede consultar el estado del pago.

# Ambientes

## Pruebas

```http
POST https://www.zonapagosdemo.com/Apis_CicloPago/api/InicioPago
```

## Producción 

```http
POST https://www.zonapagos.com/Apis_CicloPago/api/InicioPago
```
