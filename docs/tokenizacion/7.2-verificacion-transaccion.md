# 7.2 Verificación o Consulta del Estado de una Transacción

## Endpoint Producción

```text
https://www.zonapagos.com/Apis_CicloPago/api/VerificacionPago
```

## Parámetros de Entrada

| Parámetro | Tipo | Descripción |
|---|---|---|
| int_id_comercio | Int | ID comercio |
| str_usr_comercio | String | Usuario |
| str_pwd_comercio | String | Clave |
| str_id_pago | String | Identificador pago |
| int_no_pago | Int | Número pago |

> En caso de no enviar el número de pago se debe enviar `-1`.

---

## Parámetros de Salida

| Parámetro | Descripción |
|---|---|
| Int_estado | Estado ejecución |
| int_error | Código error |
| str_detalle | Detalle error |
| int_cantidad_pagos | Cantidad pagos |
| str_res_pago | Detalle transacciones |

---

## Estados de pago

| Código | Estado |
|---|---|
| 200 | Pago iniciado |
| 777 | Pago declinado |
| 888 | Pendiente iniciar |
| 999 | Pendiente finalizar |
| 4001 | Pendiente CR |
| 4000 | Rechazado CR |
| 4003 | Error CR |
| 1000 | Pago rechazado |
| 1001 | Error ACH |
| 1002 | Pago rechazado |
| 1003 | Pago fallido |
| 1 | Pago finalizado OK |

---
